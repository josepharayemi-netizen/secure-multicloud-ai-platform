# AI Governance Mapping

This demonstrator maps engineering evidence to the NIST AI RMF functions.

| Function | Repository evidence |
|---|---|
| Govern | Ownership tags, ADRs, approval boundary, threat model, model contract |
| Map | Intended use, data lineage, trust boundaries and deployment context |
| Measure | Evaluation metrics, drift-ready telemetry, SLOs and security scans |
| Manage | GitOps rollback, incident runbook, policy gates and versioned artifacts |

The model is a synthetic demonstration and is not approved for consequential production decisions.
